# nodeREX-core

O node.REX++ é uma proposta de privacidade diante do cenário atual da internet. É um projeto simples construído com o objetivo de substituir o Discord ou qualquer outra plataforma que exija nossos dados pessoais apenas para interagirmos com amigos para jogar e conversar.

O projeto não se vende como revolucionário; o intuito é construir, inspirar, ensinar e lembrar as pessoas de que, em um mundo que avança rumo a uma exigência cada vez maior de dados pessoais, os vazamentos recorrentes só provam que o discurso de "segurança" é apenas uma forma de capitalizar, explorar ou destruir a nós mesmos.
